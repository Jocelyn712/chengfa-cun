# 乘法村

給二年級孩子在 iPad Safari 上玩的九九乘法遊戲。幫村民做事（每組一樣多，算總數），拿到木材，把村莊蓋起來。

## 開始玩

iPad Safari 打開 <https://jocelyn712.github.io/chengfa-cun/>，再按「分享」→「加入主畫面」，以後從主畫面的圖示打開。

## 在自己的電腦上跑

在這個資料夾啟動本機伺服器，再用瀏覽器打開 `http://localhost:8780`：

```bash
python3 -m http.server 8780
```

同一個 Wi-Fi 的 iPad 可以用 `http://<電腦名稱>.local:8780` 連進來。直接雙擊 `index.html` 不行，因為程式用的是 ES 模組，需要經過伺服器。

### 關於存檔

- 進度存在「這個網址」的 Safari 資料裡。換網址（例如 `.local` 改用 IP）會看不到原本的進度。
- 舊版（木材共用一堆）的存檔會自動轉成分地點存，原本的木材平均分給八個地點，蓋好的進度留著。
- 主畫面圖示和 Safari 分頁也是分開存的。
- Safari 可能清掉太久沒開的網站資料；從主畫面圖示打開比較不會被清。
- 搬家或保險起見：用家長頁的「備份碼」複製、還原。

## 家長頁

點頁面最下方的「家長頁・學習紀錄與備份」，或直接打開 <https://jocelyn712.github.io/chengfa-cun/#parent>。可以看到 72 個算式各自的狀態（自己答對／用線索或答錯後完成／動手看過／跳過／還沒練），以及備份、還原、全部重來。孩子玩的畫面不會顯示這些評語。

## 遊戲設計重點

- **修橋**：第一段每排 6 格、2 排，點一下搬一捆，不考試。第二段 3 排，先決定領幾塊；領少了會留下閃爍的空格可以補領，領多了放岸邊，都不用重來。
- **村莊**：河這岸是 2～5，過橋是 6～9。每個地點用木材升級三次，第三級會有村民搬進來（共 8 位）。
- **木材分地點存**：在鞋店幫忙拿到的木材只能蓋鞋店，所以每個乘法表都要練到，不能靠 2 的乘法把整個村莊蓋完。每級要 3、6、12 塊，一個地點蓋滿 21 塊。
- **重複的題目給得少**：一個算式第一次自己答對給 3 塊，用線索或答錯後完成給 2 塊，已經自己答對過的再做一次只給 1 塊。還沒熟的題目永遠給滿額，所以一直用線索也不會卡住。全部蓋完大約要答對 56 題，平均每個地點 7 題。
- **對岸要過橋才去得了**：雞舍、活動中心、章魚池、棋盤廣場在橋修好以前蓋著霧，點了只會說「修好橋才過得去」，今日小任務也只出 2～5。走過橋時多的木板會堆在雞舍旁邊，剛好夠蓋第一級。
- **小人就是你**：村莊裡點哪個地方，小人就走到那家門口；要去對岸會先走到橋頭，再從橋上過河。橋還沒修好的話，走到橋頭就停住。
- **🌿 長草**：還在蓋的地點去過之後 3 天沒回去就會長草，地圖和首頁都看得到；回去幫一次忙就除草，那個地點多送 3 塊木材。蓋滿三級的不長草，長草也不扣任何東西，只是多一個回去的理由。（這招學自同系列的「小熊的生字森林」。）
- **任務畫面**：每組先是關著的箱子，箱子上寫每組幾個。線索一層一層開：打開一組看看 → 一組一組打開（自動累加）→ 用學過的（少一組的算式做過才出現）。沒有「直接給答案」的按鈕，數字一定由孩子自己輸入。
- **新題與複習**：6～9 第一次遇到的算式先動手打開看，不用先答；2～5 直接讓孩子想。卡住的題目隔三個動作或下次打開才再出。修完第二段橋後，過一會會在雞舍遇到 6×3。
- **今日小任務**：一次推薦兩題，可以跳過、隨時停，沒有計時、扣分或卡關。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面骨架、頂部列 |
| `css/style.css` | 版面（橫向、直向 iPad）、按鈕、動畫 |
| `js/data.js` | 2～9 各地點的情境文字、升級花費、村民 |
| `js/model.js` | 存檔、作答紀錄、推薦題目、各地點木材、對岸解鎖、修橋木板計算、備份碼 |
| `js/art.js` | 所有像素圖（SVG）：村莊、橋、每組物品、箱子、小人走的路線 |
| `js/main.js` | 畫面與操作 |
| `tests/model.test.mjs` | 單元測試 |
| `icon.png` | 主畫面圖示 |
